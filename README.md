# কৃষকের বন্ধু (Krishoker Bondhu)

কৃষকদের জন্য বাংলা ওয়েবসাইট: ছবি দিয়ে AI রোগ নির্ণয়, বাজার দর, আবহাওয়া ও পরামর্শ, রোগ-পোকার গাইড, আর সবকিছু আপডেট করার জন্য অ্যাডমিন প্যানেল।

**Stack:** Next.js (App Router) + Tailwind + TypeScript, Claude API (ছবি বিশ্লেষণ), Open-Meteo (আবহাওয়া, API key লাগে না)।

## চালানোর নিয়ম

```bash
npm install
cp .env.example .env.local   # তারপর ভ্যালুগুলো বদলান
npm run dev                  # http://localhost:3000
```

`.env.local`-এ যা লাগবে:

| Key | কাজ |
| --- | --- |
| `ADMIN_PASSWORD` | অ্যাডমিন লগইন পাসওয়ার্ড (শক্ত দিন) |
| `SESSION_SECRET` | লগইন কুকি সাইন করার র‍্যান্ডম স্ট্রিং (`node -e "console.log(require('crypto').randomBytes(32).toString('hex'))"`) |
| `ANTHROPIC_API_KEY` | রোগ নির্ণয়ের জন্য Claude API key |
| `ANTHROPIC_MODEL` | (ঐচ্ছিক) মডেলের নাম, ডিফল্ট `claude-sonnet-5-5` |

## অ্যাডমিন প্যানেল

`/admin` → পাসওয়ার্ড দিন। এখান থেকে:

- **বাজার দর:** একটা একটা করে যোগ/এডিট/মুছুন, অথবা CSV-র মতো করে অনেকগুলো একসাথে পেস্ট করুন (`ফসল,একক,দাম,বাজার,জেলা`)
- **আবহাওয়া পরামর্শ:** জরুরি সতর্কতা দিন, চাইলে নির্দিষ্ট জেলার জন্য
- **রোগ-পোকা:** তথ্য যোগ করুন। এটা AI-এর রেফারেন্সেও যায়
- **ঘোষণা:** হোম পেজের ঘোষণা
- **সেটিংস:** সাইটের নাম, স্লোগান, হেল্পলাইন

শুরুতে কিছু **নমুনা** দাম ও রোগের তথ্য থাকে ("নমুনা" ট্যাগ সহ)। এগুলো আসল তথ্য দিয়ে বদলে নিন; সেভ করলেই ট্যাগ চলে যায়। রোগের নমুনা তথ্য কৃষি বিশেষজ্ঞকে দিয়ে যাচাই করুন।

## ডেটা কোথায় থাকে

`data/db.json` ফাইলে। নিজের কম্পিউটার বা VPS-এ চালালে সরাসরি কাজ করবে (ব্যাকআপ নিতে এই ফাইলটা কপি করুন)।

**Vercel/Netlify-তে ডিপ্লয় করলে এটা কাজ করবে না** (ডিস্ক read-only)। তখন `lib/db.ts`-এর `getDB()` ও `updateDB()` Supabase দিয়ে বদলান। বাকি কোড একই থাকবে।

## নিরাপত্তা

- অ্যাডমিন পাসওয়ার্ড সার্ভারে যাচাই হয়, কুকি `httpOnly` ও সাইনড
- প্রতিটি অ্যাডমিন অ্যাকশন আলাদাভাবে লগইন যাচাই করে
- `/api/diagnose`-এ IP প্রতি ঘণ্টায় ১০টি অনুরোধের সীমা (সার্ভারের মেমরিতে; বেশি ট্র্যাফিকে Redis/Upstash ব্যবহার করুন)
- AI কে নির্দেশ দেওয়া আছে কীটনাশকের নির্দিষ্ট মাত্রা না বলতে এবং কৃষি অফিসারের পরামর্শ নিতে বলতে
